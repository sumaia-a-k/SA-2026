The Word Ladder Problem

Session 2 · Describing a problem: states, actions, goal and cost

The question

You get a start word and a goal word with the same length. Change the start word into the goal word.

  • In one step, change exactly one letter. Do not add, remove or move letters.
  • Every new word must be a real word from the dictionary.
  • Every step costs 1.

    How does the action find the next words?

    For each position in the word, try every letter from a to z. Keep the new word only if it is in the dictionary. For a 3-letter word this is 3 × 25 = 75 tries, but only a few are real words.

    Check yourself

    1. Is the maze action and this action the same kind?

    No. In the maze, one action gives 0 or 1 state. Here, one action can give many states. This is why apply() returns a Collection.

    2. Can we go from "cat" to "sky"?

    No. No ladder in our dictionary reaches "sky". A search can end with no solution, and that is a correct answer.

    3. Can we go from "cat" to "dogs"?

    No. One step never changes the length of the word. Our Java code stops with an error if the two words have different lengths.

    4. The example above uses 4 steps. Is there a shorter ladder from "cat" to "dog"?

    5. Is the goal word part of the state?

    No. It is the same for every state. In our code it is kept once (static) and shared by all states.
