> **Note:** this Python code was generated by AI, based on the Java code in [`../src`](../src).

This folder has the same code as the Java version: the same classes, the same algorithms and the same examples.

You can work in Java or in Python. Choose the language you are more comfortable with.

## What you need

**Python 3.10 or newer.** You don't need to install anything else. The code uses only what comes with Python.

Check your version:

```
python --version
```

The command name is not the same on every computer:

| Your system | Command |
|---|---|
| Windows | `python` (or `py`) |
| macOS / Linux | `python3` |

In the commands below we write `python`. Change it to `py` or `python3` if needed.

## How to run

Open a terminal **inside the `SA-2026/python` folder** (the folder with this README in it).

Python has **no compile step**. It reads the `.py` files directly, so you don't need `run.bat`, `run.sh` or an `out` folder.
After every change, just run the command again.

| What | Java (inside `SA-2026`) | Python (inside `SA-2026/python`) |
|---|---|---|
| Compile | `.\run.bat` or `./run.sh` | nothing to do |
| Run the main program | `.\run.bat` or `./run.sh` | `python -m sa2026.main` |
| Maze demo | `java -cp out sa2026.problems.maze.MazeDemo` | `python -m sa2026.problems.maze.maze_demo` |
| Word ladder demo | `java -cp out sa2026.problems.wordladder.WordLadderDemo` | `python -m sa2026.problems.wordladder.word_ladder_demo` |
| Maze demo (student version) | `java -cp out sa2026.problems.incomplete_code.maze.MazeDemo` | `python -m sa2026.problems.incomplete_code.maze.maze_demo` |
| Word ladder demo (student version) | `java -cp out sa2026.problems.incomplete_code.wordladder.WordLadderDemo` | `python -m sa2026.problems.incomplete_code.wordladder.word_ladder_demo` |
| Check your BFS (student version) | `java -cp out sa2026.algorithms.incomplete_code.BFSDemo` | `python -m sa2026.algorithms.incomplete_code.bfs_demo` |

The rule is simple: take the Java class name, write the file name in `snake_case`, and don't add `.py`.

### Why `-m`?

`-m` means "run this module". Python then starts from the current folder, so it can find the `sa2026` package and lines like `from sa2026.core.node import Node` work.

If you run a file directly, for example `python sa2026/problems/maze/maze_demo.py`, Python starts from the folder of that file and can't find the package. You get this error:

```
ModuleNotFoundError: No module named 'sa2026'
```

The same error comes if you are in the wrong folder. Go into `SA-2026/python` and use `-m`.

### VS Code and PyCharm

- **VS Code:** the "Run Python File" button runs the file without `-m`, so you get the error above. Use the terminal command.
- **PyCharm:** open the `python` folder as the project. Then the Run button works, because PyCharm adds the project folder to the Python path.

## From Java names to Python names

Python has its own style. So the names are a little different, but the meaning is the same.

| Java | Python | Note |
|---|---|---|
| `MazeState.java` | `maze_state.py` | file and method names use `snake_case` |
| `getInitialState()` | `get_initial_state()` | |
| `node.getState()`, `node.getDepth()` | `node.state`, `node.depth` | Python usually has no getters. You read the field directly. |
| `private int row;` (no getter) | `self._row` | `_` at the start = "use it only inside the class". Python doesn't stop you, it is only a rule. |
| `static Maze maze;` | `maze = None` in the class body | a class variable, shared by all objects |
| `final` | (no such word) | the comments say which fields must not change |
| `this` | `self` | |
| `super(x)` | `super().__init__(x)` | |
| `interface`, `abstract class` | class that extends `ABC`, with `@abstractmethod` | |
| `toString()` | `__str__()` | |
| `equals()`, `hashCode()` | `__eq__()`, `__hash__()` | |
| `compareTo()` | `__lt__()` | "less than", used by priority queues |
| `null`, `true`, `false` | `None`, `True`, `False` | |
| `List` / `ArrayList` | `list` | |
| `HashSet` | `set` | |
| `Queue` / `LinkedList` | `deque` | from the `collections` module |

## Python things that are more than beginner level

If you only know basic Python (variables, `if`, loops, functions, lists), these parts of the code may be new to you.
Each one also has a short comment in the code.

| Topic | Where you see it | In short |
|---|---|---|
| Classes, `self`, `__init__` | every file | A class is a plan for objects. `__init__` is the constructor. `self` is the object itself (like `this` in Java). |
| Inheritance | `class MazeState(State)` | `MazeState` gets everything from `State` and adds its own parts. |
| Abstract classes: `ABC`, `@abstractmethod` | `core/state.py`, `core/problem.py` | A class with "empty" methods that the child class **must** write. Python doesn't let you create an object if one is missing. |
| Special methods: `__str__`, `__repr__`, `__eq__`, `__hash__`, `__lt__` | `core/state.py`, `core/node.py` | Python calls them for you: `print(x)` calls `__str__`, `a == b` calls `__eq__`, a `set` calls `__hash__`, `a < b` calls `__lt__`. |
| The `__eq__` / `__hash__` trap | `core/state.py` | If you write `__eq__` but forget `__hash__`, you get `unhashable type` when the state goes into a set. |
| Type hints | `def apply(self, s: State) -> list[State]:` | They say what type a value should be. Python **doesn't** check them when it runs. They help you and your editor read the code. `Node \| None` means "a Node or None". |
| Default values instead of many constructors | `core/node.py`, `core/search_algorithm.py` | Java has 2 or 3 constructors. Python has one `__init__` with default values like `use_graph_search=False`. |
| `*lines`, `*words` | `maze.py`, `word_dictionary.py` | "Give me any number of values" (like `String...` in Java). Inside the method it is a tuple. |
| `@staticmethod` | `Maze.from_lines()`, `WordDictionary.three_letter_words()` | A method of the class, not of one object (like `static` in Java). |
| Class variable vs object variable | `maze/maze_state.py` | A variable in the class body is shared by all objects. Change it with `MazeState.maze = ...`, **not** with `self.maze = ...`. |
| `deque` | `algorithms/bfs.py` | A fast queue. `append()` adds at the end, `popleft()` takes from the front. A normal list is slow with `pop(0)`. |
| `set` and `in` | `algorithms/bfs.py`, `word_dictionary.py` | `state in explored` is fast, because a set uses the hash and doesn't check the items one by one. |
| `while frontier:` | `algorithms/bfs.py` | An empty list, set or deque counts as `False`. So this means "while the queue is not empty". |
| `x if condition else y` | `core/node.py`, `maze_demo.py` | A short `if` in one line, like `condition ? x : y` in Java. |
| f-strings with a width | `main.py` | `f"{name:<24}"` puts `name` on the left side of 24 characters. `f"{steps:5}"` puts the number on the right side of 5 characters. |
| Slicing | `wordladder/change_letter_action.py` | `word[:i]` = the letters before position `i`, `word[i + 1:]` = the letters after it. |
| `pass` | the student versions | "Do nothing". Python needs at least one line inside a method. Remove it when you write your code. |
| `print(x, end="")`, `flush=True` | `word_ladder_demo.py`, `bfs_demo.py` | Print without going to a new line. `flush=True` = show the text now, not later. |
| `if __name__ == "__main__":` | `main.py` and the demos | Run `main()` only when this file is started, not when another file imports it. |
| Packages, `__init__.py`, `python -m` | this README | See "How to run" above. |
| `TYPE_CHECKING` | `core/problem.py` | A trick to avoid a "circular import" (two files that import each other). You can skip this one for now. |
