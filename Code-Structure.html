1The big picture: 4 parts

The code has 4 parts. Click any name to see what it is and what it has.

The main idea: the algorithms only know the core types (State, IAction, Problem). They do not know the maze or the puzzle. So every algorithm works with every problem, and a new problem needs no change in the algorithms.

6A new problem? Write 3 classes

  
To add your own problem, write a state, an action and a problem. Then every algorithm can solve it, with no change.
